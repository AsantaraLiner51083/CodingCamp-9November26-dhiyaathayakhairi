# Product

**Dagobert Expense & Budget Visualizer** — a client-side personal finance tracker built as a mandatory assignment for the RevoU Mini Course Coding Camp.

## Core Features
- Add, view, and delete expense transactions (name, amount, category)
- Three fixed categories: Food, Transport, Fun
- Monthly budget limit with over-budget warning
- Sort transactions by amount (ascending / descending / default)
- Pie chart showing spending distribution per category (Chart.js)
- Dark / light mode toggle
- All data persisted in browser `localStorage` — no backend

## Target Users
Individual users tracking daily personal expenses in IDR (Indonesian Rupiah).
